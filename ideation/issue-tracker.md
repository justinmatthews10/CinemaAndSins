## Status Legend

- **Not Started** — No work begun. GitHub issue may not be created yet.
- **In Progress** — Actively being implemented. Checkpoint file exists in `harness/checkpoints/`.
- **In Review** — PR open, awaiting review.
- **Complete** — Merged to `main`, issue closed.
- **Blocked** — Waiting on a dependency or external input.
